## 📌 Visão Geral
Conjunto de rotinas e extensões desenvolvidas para eliminar gargalos de lentidão e trabalho repetitivo na consulta e baixa de Ordens de Serviço operacionais em sistemas ERP baseados em navegador.

## 🚀 Funcionalidades
- **Super Painel Operacional:** Interface injetada no navegador para busca e filtragem em lote com paginação inteligente.
- **Extração Estruturada:** Normalização de datas, identificadores de técnicos e tipos de ocorrência para relatórios consolidados em Excel.
- **Tratamento de Exceções:** Validação de timeouts de rede e respostas HTTP para evitar travamentos de interface.
